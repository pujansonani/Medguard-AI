Clinical Practice Guideline:
Norepinephrine 1st-line in septic shock. Target MAP ≥ 65 mmHg. If dose > 0.25 mcg/kg/min, add Vasopressin (0.03 U/min). Max threshold: 0.50 mcg/kg/min.

Surviving Sepsis Campaign (SSC 2021) 1-Hour Bundle:

1. Measure Serum Lactate Level

Re-measure within 2-4 hours if initial lactate > 2.0 mmol/L to guide resuscitation.

2. Obtain Blood Cultures Prior to Antibiotics

Draw 2 sets (aerobic + anaerobic) without delaying antimicrobial initiation > 45 mins.

3. Administer Broad-Spectrum IV Antimicrobials

Initiate empiric broad-coverage therapy (e.g. Vancomycin + Cefepime) within 60 mins.

4. Administer 30 mL/kg Crystalloids for Hypotension or Lactate ≥ 4.0

Use balanced crystalloids (Plasma-Lyte / Lactated Ringer's) within 3 hours.

5. Apply Vasopressors if MAP < 65 mmHg During/After Resuscitation

Maintain target MAP ≥ 65 mmHg with Norepinephrine.
